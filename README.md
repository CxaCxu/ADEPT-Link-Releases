# ADEPT Link

Version 0.2.2. ADEPT Link updates itself: it looks here, downloads a new version
and installs it when you close the app.

## Download

- Windows app: [ADEPT-Link-Windows-0.2.2.zip](https://raw.githubusercontent.com/CxaCxu/ADEPT-Link-Releases/main/ADEPT-Link-Windows-0.2.2.zip) (unzip, open ADEPT Link.exe)
- Windows VST3: [ADEPT-Link-VST3-Windows-0.2.2.zip](https://raw.githubusercontent.com/CxaCxu/ADEPT-Link-Releases/main/ADEPT-Link-VST3-Windows-0.2.2.zip) (unzip into C:\Program Files\Common Files\VST3)
- Mac (app, VST3 and AU): [ADEPT-Link-Installer-0.2.2.pkg](https://raw.githubusercontent.com/CxaCxu/ADEPT-Link-Releases/main/ADEPT-Link-Installer-0.2.2.pkg)

## New in this version

- PROJECTS page: NEW PROJECT always opens a blank project
- With the ADEPT unit connected, a new project asks: SEND PROJECT TO ADEPT or LOAD PROJECT FROM ADEPT
- CONDUCT page: the same colours as the unit. The tab is grey when the ADEPT unit is not connected

This page holds the finished files only. It shows the newest version.
